# 932420.Vladimirova.Alisa.lab6

Веб-приложение «Эко-активизм» на базе Node.js и Express с поддержкой технологии PWA и REST API конвертера валют

## Требования для запуска на другом ПК
Для работы проекта на компьютере должен быть установлен Node.js

## Пошаговая инструкция по запуску

1. **Скачайте репозиторий** на компьютер

2. **Откройте терминал в папке проекта** (где находится файл `package.json`) и установите необходимые зависимости (библиотеку Express):
   ```bash
   npm install
   ```

3. **Запустите локальный сервер:**
   ```bash
   node server.js
   ```
   В терминале появится сообщение: `Сервер работает на http://localhost:3000`.

4. **Откройте сайт в браузере** (Google Chrome или Microsoft Edge), перейдя по адресу:
   `http://localhost:3000`

## Проверка работы маршрутов (Вариант 7 — Конвертер валют)

- **Главная страница:** `http://localhost:3000/`
- **Страница «О себе»:** `http://localhost:3000/about`
- **Успешный запрос к API конвертера:**  
  `http://localhost:3000/api/convert?from=USD&to=RUB&amount=100` 
- **Проверка обработки ошибок (HTTP 400):**  
  `http://localhost:3000/api/convert?from=USD&to=RUB&amount=-10` *(некорректная сумма)*  
  `http://localhost:3000/api/convert?from=GBP&to=RUB&amount=100` *(неизвестная валюта)*

## Проверка PWA и офлайн-режима
1. Нажмите значок установки в правой части адресной строки браузера, чтобы установить сайт как отдельное приложение.
2. Откройте инструменты разработчика (`F12`) → вкладка **Application** → **Service Workers**, поставьте галочку **Offline** и обновите страницу (`F5`) — сайт продолжит работать из кеша без интернета.
